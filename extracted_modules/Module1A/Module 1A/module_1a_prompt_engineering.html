Module 1A: Crafting Effective Prompts for Construction

Project Manager

📋 Generate Weekly Project Summary from Raw Data

Context

You have scattered project updates from team members. You need a professional executive summary in 5 minutes instead of spending 1 hour compiling it.

❌ Vague Prompt
Summarize this week's work
✓ Better Prompt
Create a weekly project summary for IISER Library project (Tirupati, AP). Include: • Completed milestones this week • % progress vs. target • Budget spent vs. budget allocated • Top 3 risks/delays • Next week's priorities Keep it under 150 words, professional tone.
🎯 Be specific: Include project name, location, stakeholders involved
📊 Define structure: Tell AI exactly what sections you want (milestones, budget, risks)
⏱️ Set constraints: Word limits, tone (professional/casual), date formats
📎 Provide context: Paste raw meeting notes, emails, or status updates

💡 Pro Tip: Use this prompt template: "Create a [type] for [project] including [specific sections]. Keep it [length] and use [tone]."

Site Supervisor

🏗️ Convert Field Notes into Formal Daily Site Report

Context

You've taken quick notes on your phone all day. Need to turn them into a formal report that the PM and client can read.

❌ Weak Prompt
Turn this into a report: "Had 45 workers. Poured concrete north wing. Weather was hot. Some delays"
✓ Strong Prompt
Format as daily site report (date: 15-Aug-2026). Raw notes: "45 workers on-site. Poured 80 cubic meters concrete north wing foundation (target: 100m³ - 20% below due to heat). Weather: 42°C, high humidity. 2-hour lunch break extended by safety order. Rebar inspection passed. No incidents." Include: Date | Weather | Workforce | Major Activities | % of Planned Work Completed | Issues & Delays | Safety Notes | Next Day Plan
📍 Include meta-data: Date, project name, weather, workforce count
🔢 Add numbers: Quantities (concrete poured, workers), percentages, times
⚠️ Highlight issues: Delays, weather impacts, safety incidents, deviations
👥 Mention context: Workforce, equipment used, inspections passed

💡 Pro Tip: Voice-record your notes on phone, transcribe with Whisper/Google Docs, then paste to AI. Saves 30 mins daily!

Safety Officer

🛡️ Create Safety Protocol from Regulatory Requirements

Context

You have OSHA/Indian labor code requirements but need to turn them into an actionable site-specific procedure for DEC Infra teams.

❌ Generic Prompt
Write a safety protocol for height work
✓ Tailored Prompt
Create a site safety protocol for DEC Infra - IISER Tirupati project (height work above 2 meters). Target audience: Site supervisors & workers (use simple language). Include: • Scope (applies to work >2m height) • Required PPE (with DEC company gear codes) • Pre-work checklist (3-5 items) • Responsibilities (supervisor, worker, safety officer) • Emergency procedures • Non-compliance consequences Comply with Indian Building Code + OSHA guidelines. Make it 1 page, printable.
🏢 Company-specific: Use DEC Infra name, actual project names, company standards
👥 Right audience: Write for site workers (simple language), not legal teams
✅ Compliance mention: Reference actual codes (Indian BC, OSHA, local regulations)
📋 Practical format: Checklists, bullet points, easy to print & post

💡 Pro Tip: Ask AI to "summarize in 3 sentences" at the end so busy PMs get the gist instantly.

Project Manager

✉️ Draft Professional Vendor Communications

Context

Need to send a vendor a detailed RFQ (Request for Quote) but don't want to spend time on perfect wording.

❌ Unclear Prompt
Write an email asking for a quote on concrete
✓ Detailed Prompt
Draft professional RFQ email to concrete supplier. Details: • Project: IISER Library, Tirupati • Requirement: 150 cubic meters M30 grade concrete • Delivery timeline: Week of 20-Aug • Delivery location: Site address [add address] • Required docs: COA (Certificate of Analysis), delivery slip • Payment terms: 30-day net • Compliance: Indian Standards IS 456 Keep email tone: professional but friendly. Include subject line. Sign as [Your Name], DEC Infra.
🏷️ Exact specs: Grades, quantities, delivery dates, standards (IS 456, etc.)
💼 Business details: Payment terms, inspection requirements, penalties
🎯 Clear expectations: What docs they must provide (CoA, test reports)
📧 Tone setting: Request "professional but friendly," "formal," etc.

💡 Pro Tip: Tell AI "Ensure all compliance points are covered" - it'll catch missing requirements you might forget!
